# 五子棋 · Gomoku (Pygame)

> 基于 Pygame 的五子棋游戏，含**人机对战**与三档 AI 难度，界面为棋盘 + 右侧控制面板。

## 两个版本

| 文件 | 说明 |
|------|------|
| `gobang.py` | 基础版：棋盘渲染 + 三档难度 + 简单启发式打分 AI |
| `gobang_plus.py` | 升级版：**Minimax + Alpha-Beta 剪枝**、多线程 AI、程序化音效、棋谱回放、会话胜率统计、开局库、改进评估函数 |

## 主要特性（升级版）

1. Minimax + Alpha-Beta 剪枝搜索 AI
2. 多线程 AI 计算（界面不卡顿）
3. 程序化音效（无需外部音频文件）
4. 棋谱回放（逐步查看历史落子）
5. 会话胜率统计
6. 开局库（常见定式）
7. 改进评估函数（双威胁检测、位置权重）

## AI 难度

| 难度 | 搜索深度 |
|------|----------|
| 简单 | 1 |
| 中等 | 3 |
| 困难 | 5 |

```bash
python gobang_plus.py
```
